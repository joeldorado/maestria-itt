# Maestría ITT

Repositorio con las actividades y proyectos de la maestría en el Instituto Tecnológico de Tijuana.

## Materias

| Carpeta | Materia | Actividades |
|---------|---------|-------------|
| [`programacion-orientada-a-objetos/`](programacion-orientada-a-objetos/) | Programación Orientada a Objetos (POO) | 1 |

## Estructura

Cada materia tiene su propia carpeta y dentro de ella una carpeta por actividad:

```
maestria-itt/
├── README.md
└── <materia>/
    ├── README.md
    └── actividad-XX-<tema>/
        ├── README.md
        └── <codigo>
```

## Requisitos

- Python 3.10 o superior para las actividades en Python.
